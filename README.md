# GutenMorgen — ChatGPT Personal Workspace Framework

## Installation

1. Open Violentmonkey.
2. Create a new script.
3. Copy the contents of `src/GutenMorgen.user.js`.
4. Save.
5. Reload ChatGPT.

## Architecture

- core/config.js — configuration model
- core/storage.js — persistent settings
- core/logger.js — debug logging
- dom/project-detector.js — project detection
- features/themes.js — visual themes

Current version:
- project theming
- local settings storage
- debug logging
- Kernix | Rust preset

Future:
- settings panel
- custom icons
- project grouping
- command palette
- prompt snippets
